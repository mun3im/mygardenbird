# Regional species ranking (50-species catalogue)

Generated by `pipeline/rank_with_nd.py` from the per-species catalogue CSVs
fetched by Stage 1 on 2026-11-14 (the Olive-backed Sunbird file is the
2026-11-11 fetch; see the caveat below). The script merges per-species CSVs
case-insensitively, because several catalogue CSVs had casing-duplicate
filenames (e.g. `Asian_koel.csv` vs `Asian_Koel.csv`).

> **Regenerated 2026-11-20.** An earlier version of this file reported inflated
> counts for several species (for example Yellow-vented Bulbul 282 regional
> files, Asian Koel 715, Common Tailorbird 764). Those came from a run that
> counted casing-duplicate files twice. The figures below are from a fresh run;
> the underlying table is `project_csv/regional_ranking_nd.{csv,md}`.

Regional filter per Stage 1: longitude 60-140E, latitude north of 11S, or ASEAN country of origin (for missing coordinates); recordings >= 3 s. There is **no northern latitude bound** (the 11S floor only excludes northern Australia), so temperate-range species such as the Eurasian Tree Sparrow look better supplied than they are. "non-ND" additionally excludes CC BY-NC-ND sources, which cannot be used (3-second segmentation is a derivative work).

Species in the v2.0 (15-class) dataset are marked **in bold**, and the last column gives each class's released 16 kHz clip count. Eleven classes reach the 600-clip target; four stop below it because every usable (non-ND) regional recording has been used.

## Ornate Sunbird caveat

The catalogue CSV is still filed under `Olive-backed_Sunbird.csv` (eBird code
`olbsun4`), because Xeno-canto has not adopted the split: a query for
*Cinnyris ornatus* returns nothing and `Ornate_Sunbird.csv` is an empty
placeholder (it cannot be built). The Ornate Sunbird class is therefore
*part of* the Olive-backed Sunbird complex, assembled by subspecies tag and
locality. The complex row below counts the whole regional pool (376 records, 272 non-ND),
which is larger than the class's eligible material.

Subspecies tags in that pool (regional records; non-ND in brackets):

| Group | `ssp` tag | Records | non-ND |
|---|---|---:|---:|
| *C. ornatus* (included) | *ornatus* (incl. 2 spelled "ss ornatus") | 48 | 28 |
| *C. ornatus* (included) | *flammaxillaris* | 82 | 56 |
| *C. ornatus* (included) | *rhizophorae* | 8 | 8 |
| *C. ornatus* range | blank | 122 | 91 |
| Excluded taxa | *infrenatus*, *plateni*, *jugularis*, *aurora*, *frenatus*/*frenata*, *teysmanni*, *clementiae*, others | 116 | 89 |

*flammaxillaris* and *rhizophorae* are subspecies of *C. ornatus* under the
eBird/Clements split, so counting only the literal *ornatus* tag understates
the tagged pool. Even so, the tags alone do not reach 600 clips. The 95
contributing sources in the released class are:

| `ssp` tag | Sources | Clips |
|---|---:|---:|
| *ornatus* | 13 | 70 |
| *flammaxillaris* | 36 | 241 |
| *rhizophorae* | 5 | 44 |
| blank (assigned by locality alone) | 41 | 245 |
| **Total** | **95** | **600** |

So 245 of the 600 clips (40.8%) rest on locality, not a tag. None of the 95
sources is filed by Xeno-canto as Ornate Sunbird; all are filed as
Olive-backed Sunbird. The excluded taxa (Philippine and Wallacean forms) were
removed from the class (R1-1c).

An earlier version of this file said only 92 recordings (53 non-ND) carried an
`ssp=ornatus` tag out of 718 regional records. Those figures do not reproduce
from the catalogue (376 regional records, 48 tagged *ornatus*, 28 of them
non-ND) and should not be quoted.

The Olive-backed Sunbird complex's 272 non-ND files include taxa excluded from the class; the eligible *C. ornatus* pool is 183 (28 *ornatus* + 56 *flammaxillaris* + 8 *rhizophorae* + 91 blank-tag), still above the 139 line.

**Source count, not hours, bounds the class size.** Because segmentation
samples sparsely (at most 10 segments per recording, 4.2-6.3 clips per
contributing source), a class needs roughly 120-140 usable *recordings* to
reach 600 clips. Among the classes that reached 600, the fewest usable sources
is 139 (Scarlet-backed Flowerpecker); among the four that did not, the most is
126 (Collared Kingfisher). Hours do not separate them: the Flowerpecker reached
600 from 1.16 non-ND hours, while the Yellow-vented Bulbul stopped at 540 from
1.42. Supply alone did not decide the species list either: 17 of the 50 species
have at least 139 usable files, including six that are not in the dataset
(Swinhoe's White-eye, Greater Racket-tailed Drongo, Eurasian Tree Sparrow,
Red-whiskered Bulbul, Brown-throated Sunbird, Lineated Barbet).

## Notes on species not included despite apparently sufficient material

- **Greater Racket-tailed Drongo** (349 non-ND files) -- forest/jungle species, outside the garden-bird scope, and not on the MY Garden Birdwatch count sheet.
- **Eurasian Tree Sparrow** (226 non-ND files) -- the apparent supply is an artefact of the missing northern latitude bound: median latitude 31.1N, 64% of its regional records above 25N, and 83 from Mongolia, Russia, Kazakhstan, Uzbekistan, Japan and Korea. Restricted to ASEAN it has about 56 usable sources (0.66 h).
- **Swinhoe's White-eye** (215 usable sources) -- ample material; deferred to a subsequent release, not excluded on any species property. See the SciData paper's species-selection table.
- **House Crow** (106 usable sources) -- below the ~126-139 usable-source range the dataset needs to reach 600 clips; insufficient regional material, not a scope or congener exclusion. The files are downloaded, so the next release starts without a fetch.
- **Red-whiskered Bulbul** (181 usable) -- well supplied but an introduced, largely escaped-cage-bird population in Peninsular Malaysia, so it may fail the native-resident criterion; left out.
