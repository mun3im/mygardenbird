# Regional species ranking (50-species catalogue, duplicate-casing fixed)

Generated by `pipeline/rank_with_nd.py` (merges per-species CSVs case-insensitively -- several catalogue CSVs had casing-duplicate filenames, e.g. `Asian_koel.csv` vs `Asian_Koel.csv`, that were previously splitting one species' counts across two rows).

Regional filter per Stage 1: longitude 60-140E, latitude north of 11S, or ASEAN country of origin (for missing coordinates); recordings >= 3s. "non-ND" additionally excludes CC BY-NC-ND sources, which cannot be used (3-second segmentation is a derivative work).

Species currently in the v2.0 (15-species) dataset are marked **in bold**. The
catalogue CSVs are still filed under the eBird code `olbsun4` / filename
`Olive-backed_Sunbird.csv`, but the entry is shown here as **Ornate Sunbird**
to match its current v2.0 taxonomic name (same underlying Xeno-Canto records).

## Notes on species not included despite apparently sufficient material

- **Greater Racket-tailed Drongo** (349 non-ND files) -- forest/jungle species, outside the garden-bird scope.
- **Eurasian Tree Sparrow** (226 non-ND files) -- insufficient regional samples despite the raw non-ND file count (see Stage 1 regional filter).
- **Swinhoe's White-eye** (215 usable sources) -- ample material; deferred to a subsequent release, not excluded on any species property. See the SciData paper's species-selection table.
- **House Crow** (106 usable sources) -- below the ~126-139 usable-source threshold the dataset needs to reach 600 clips; insufficient regional material, not a scope/congener exclusion. The paper's exclusion-reason table was corrected to reflect this (previously said "sufficient material").
